# METEHAN V0.7 — Ücretsiz Yerel Sürüm

- OpenAI API anahtarı gerekmez.
- Genel sohbet, telefona bir kez indirilen GGUF model ile cihaz içinde çalışır.
- Varsayılan model: Qwen2.5 0.5B Instruct Q4_K_M (~491 MB), Apache-2.0.
- Telefon eylemleri model olmadan da yerel kural motoruyla çalışır.
- Kamera temel nesne etiketleme için cihaz içi ML Kit kullanır.
- Wake-word cihaz içinde çalışır.

Model ağırlıkları APK'ya gömülü değildir; kullanıcı ilk kurulumda doğrudan model deposundan indirir.
